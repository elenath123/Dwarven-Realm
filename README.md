Dwarven Realm——addon to the Lord of the Rings mod for minecraft 1.7.10. Adds two new factions - the dwarves of the red mountains and the dwarves of the wind mountains, as well as all related content: mobs, achievements, waypoints, roads, shields,banners, blocks, items, structures and so on.
